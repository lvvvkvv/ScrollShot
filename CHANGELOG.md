# Changelog

## 0.2.1

- Show the crosshair immediately when region selection begins.
- Arm the display under the pointer and accept the first mouse press.
- Keep the selection cursor across non-key display overlays.
- Restore the normal pointer after completion/cancellation and guard delayed cursor refreshes.
- Add native selection regression checks.

## 0.2.0

- Adaptive light/dark workspace, unified controls and vector artwork.
- Compact capture HUD and centered preview canvas.
- Background PNG encoding and latest-result access.

## 0.1.0

- Initial regional scrolling capture, optional auto-scroll, PNG export and clipboard support.
